## 常见工具

课程文件存储管理，课程在线文档，OJ or CI, 可视化工具，云服务器 (如何向学生提供？)

从实际助教工作出发，可以把工具分为下面几类：

- **课程文档写作**：推荐使用开源文档框架 (如 [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)) 部署到自己的服务器或 GitHub Pages；也常用语雀等在线协作文档；VS Code 的 Storyteller 等插件可以辅助讲解可视化。
- **作业批阅 / 评语写作**：用简单脚本让“看作业、给分、自动跳到下一份作业”形成工作流；统一提交格式 (如 PDF / 模板表格) 便于脚本处理。
- **课程材料管理 / 文档写作**：注意版本同步和可持续更新 (参考 UC Berkeley CS375 谈到的材料管理)。
- **在线评测平台**：从 OJ 平台到 CI 平台，两者各有特点与好处，需要根据课程需求取舍。
- **可视化工具**：调试过程可视化 (如 PythonTutor、VS Code pedagogical)，以及算法本身的 demo。
- **云服务器**：如何向学生提供便捷、低成本的环境 (例如免去配环境的负担)。
