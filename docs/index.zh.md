# 计算机系助教培训 Teaching Assistants Competency


!!! note "未来规划 (2026)"

    较早的培训材料（2023 秋、2024 春）写于大语言模型深入计算机教育之前，某种程度上已经过时。

    从 2024 秋开始，培训已逐步纳入人机协同、大模型对作业/评分/答疑的影响等主题。我们也在积极开发一门新课程《计算教育研究导论》。

这个网站的结构经历过几次调整，我们希望能展示助教培训的迭代过程。

下面是当前网站结构的介绍：

[助教周刊](https://thucstac.github.io/TAC/weekly/) 尝试为助教呈现“一门课、一项作业、一篇论文”，由于难以持续收集到对助教有启发的公开材料，目前已暂停更新。

[参考资料](https://thucstac.github.io/TAC/reference/) 收录了我们认为对助教培训有用的第三方材料（链接）。

[2023 秋](https://thucstac.github.io/TAC/2023A/) 与 [2024 春](https://thucstac.github.io/TAC/2024S/) 分开组织。我们感觉这不是组织材料的最佳方式，尤其是当某一次研讨与上个学期没有太大区别时。

从 [2024 秋](https://thucstac.github.io/TAC/2024A/) 开始，我们采用“每个学期一个索引页 + 每个研讨一页”的结构（同 2024 春），并尝试按主题组织材料。此后多次研讨在不同学期间被复用（如调试、答疑、作业设计、评分查重），有时只是将同一套幻灯片更新到新学期。
