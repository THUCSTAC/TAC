# 2024 秋 · 助教朋辈分享 (TA Panel)

沿用 2024 春 "助教工作效率技巧和常见误区" 的内容。开场强调助教工作/培训的意义：好的助教经历能带来成就感、探索可能性、不再孤独; 但也要防止疲惫、失误和心理阴影，因此培训的首要目标是让助教自己的工作体验更正面，而不只是为老师、同学服务。

围绕新上岗助教的五项常见误区展开（源自与往届助教的访谈）:

- 凭感觉/一腔热血干活，没有明确的依据、分工和计划 —— 需要文字依据（课程大纲/公告）、助教间与师长的分工、以及对何时要做助教工作的计划。
- 没完成从学生到助教的身份改变 —— 每一句话都代表教学团队，作为学生可以吐槽，作为助教不可以。
- 假设学生和自己类似，或将人假设为机器 —— 不要用自己/小圈子的方式沟通，别对学生说 "RTFM"; 人不是机器，做错了就道歉，减少沟通歧义。
- 任何情况下都要尽量及时回复同学 —— 可类比 memory hierarchy, 助教答疑应定位在 "较低可用性 + 较高质量"; 课程管理类问题先查文件、找老师助教形成一致。
- 需要尽量满足每一个同学的各种要求 —— 只求满足大多数同学的合理要求; 若接受个例，要确保机会公平并公开补交扣分规则。

本学期为新上岗助教赠送《非暴力沟通》。
