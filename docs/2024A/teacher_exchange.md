# 2024 秋 · 教师交流分享 (邓俊辉)

暖场环节：自我介绍 + "我担任某某课程的助教，对助教工作现在有的疑问/曾经的疑问是..."。围绕大家提出的真实问题展开讨论。

## 同学求助于大语言模型写代码 / AI 时代作业与查重

- 想法：从前我们把白卷作为"零分"基准，现在可以将不加人为干涉的大语言模型输出的结果，作为"零分"基准。
- 想法：增加不联网的考试？按性能排名/相对水平给分？
- 如果一个同学做了很好的 prompt engineering，虽然是 AI 生成的结果，但确实是一个很好的回答，怎么处理？（这体现了这个同学自己的水平？）
- 使用 AIGC 代码引发的查重情况？如果同学说这是自己独立完成的、没有和其他人（除了 AIGC）交流？—— 做法：提前声明禁止使用 AIGC。
- 对作业做一些调整，避开那些过于经典、容易由 AIGC 直接生成的题目。

## 课标委 / coursebench 与评价

- 教评的分数过于粗糙，教评问卷也很模糊。
- 想法：拆成两部分——教师陈述自己的教学理念，学生评价"我是否认同教师的教学理念"（例如 OS 课应不应该学写 OS？）以及"教师的教学理念在课程中是否得到了实现"（例如 OS 课有没有教会写 OS？）。
- 过于精确的量化数字是否有意义？（"2.3 分的欠缺"不可能精确传递到教学团队做出"2.3 分"的努力）
- 助教的角色很模糊，似乎没有人看到过这个评价分数。

## 同学们的其他困惑

- 同学对一些课程不感兴趣；同学答疑提问的问题出在之前学期的课程，该怎么解决？—— 可能没什么办法，靠教师个人魅力？优化课程质量？课程与课程之间的问题不是一门课本身的问题，需要增加教师之间的协调、交流，以及课程资源的整理、存档、公开。
- 如果我是教师，我会怎么做？高校教学的职位非常少。
- 如何教会同学调试？尝试做调试辅导课——能讲出来的似乎对同学帮助不大，对同学有帮助的似乎又讲不太清楚。
- 线下答疑来的同学不多，线上问问题的效率不高，答疑的策略怎么办？
- 如何稳定助教的队伍（理论上本科生不让做，存在管理上的错配、教学与科研的精力冲突），让优秀助教不断涌现、让大家愿意做助教？
  - 例：计组带着大家打比赛（龙芯杯），然后划为明年的助教。
  - 奖励的缺乏？目前大家还是依靠情怀比较多？本科生管理和研究生管理的割裂？undergraduate tutor 的"名分"问题？
  - 尊重同学的隐私/自尊心（不公开的提问）；知识相关的课程前后相隔太远（例如数值分析和微积分线代相隔很远）；研究生院的中级、高级助教证书？教师资格证？
